# 🎮 Game & EXE Launcher

モダンなデザインと強力なゲーム管理機能を備えた、Windows向けの高性能ゲーム・EXEランチャーです。

---

## 🌟 主な機能

1. **ハイブリッドUI (タイル/カード ＋ リアルタイム検索)**:
   - 高解像度のアプリアイコン/カバー画像が並ぶ直感的なカード型レイアウト。
   - 上部検索バーに文字を入力すると**リアルタイムで瞬時に候補を絞り込み**。
   - **Enterキーを押すだけで、一番最初のゲームを即座に起動**できます。
   - カテゴリタブ（「すべて」「ゲーム」「download」「お気に入り」等）による素早いジャンル切り替え。
   - ダークモード/ライトモードのワンクリック切り替え。

2. **同一ゲームの自動検出 ＆ バージョン・セーブ進行度比較（★独自機能）**:
   - `D:\ゲーム` や `D:\download` など複数の場所に散らばった**同じゲーム（バージョン違いや重複）を自動判定**。
   - カード上に「🔁 重複 2件 比較」バッジを表示。
   - **比較画面**:
     - どちらのバージョンが新しいか（更新日時、ファイルサイズ、パス）
     - **内部セーブデータから進行度を自動解析**（最新プレイ日時、セーブスロット数、プレイ時間など）
     - **ワンクリックセーブデータ移行**: 古い版のセーブデータを最新バージョンのフォルダへ自動バックアップ＆引き継ぎ！

3. **Webからのアイコン/カバー画像自動検索 ＆ ピッカー**:
   - アプリ名やRJ番号をもとに、Web上から綺麗なジャケット画像やロゴアイコンを自動検索。
   - 「🔍 Webから画像を探す」を押すと、**候補画像サムネイルが一覧表示され、好きな画像をワンクリックで選択・変更**可能。
   - ローカル画像（PNG/JPG/ICO）やexe内蔵アイコンの利用も自由自在。
   - 一度取得した画像はローカルに自動キャッシュされるためオフラインでも高速表示。

4. **ライブラリフォルダ管理**:
   - 初期状態で `D:\ゲーム` と `D:\download` を登録。
   - 「📁 フォルダ管理」から、**いつでも好きなフォルダを追加・削除・一括スキャン**可能。
   - アンインストーラ（`unins*.exe`）やUnityクラッシュハンドラ（`UnityCrashHandler*.exe`）などを自動除外して**メインの起動exeだけを賢く検出**。

5. **ドラッグ＆ドロップ対応**:
   - エクスプローラーからフォルダや `.exe` をウィンドウに直接ドロップするだけで即座に登録可能。

6. **スタンドアロンEXE化**:
   - `build.bat` を実行するだけで、Pythonの入っていないPCでも単体で動くポータブルな `GameLauncher.exe` を生成。

---

## 🚀 使い方

### 1. Pythonから起動する場合
```bash
cd C:\Users\owner\.gemini\antigravity\scratch\exe-launcher
py main.py
```

### 2. 単体EXEとしてビルドする場合
フォルダ内の `build.bat` をダブルクリック（またはコマンドプロンプトで実行）してください。
完了すると、`dist\GameLauncher.exe` に単体で動作するexeファイルが生成されます。

## 📁 プロジェクト構成

```
exe-launcher/
├── main.py                  # メインGUI（カードグリッド、検索バー、タブ、ドロップ受付）
├── config_manager.py        # 設定・登録ゲーム情報の永続化 (launcher_config.json)
├── folder_scanner.py        # フォルダ巡回・メインexe自動判定・不要ファイル除外
├── game_analyzer.py         # 同一ゲーム検出・バージョン比較・セーブ進行度解析・セーブ移行
├── comparison_dialog.py     # 重複ゲームの比較・進行度表示・セーブ引き継ぎモーダル
├── icon_helper.py           # Web画像検索・exeアイコン抽出・画像キャッシュ
├── icon_picker_dialog.py     # Web画像検索候補サムネイルから選べるピッカー
├── folder_manager_dialog.py # スキャン対象フォルダ追加・管理モーダル
├── game_edit_dialog.py      # アプリ個別追加・編集モーダル
├── requirements.txt         # 依存ライブラリ一覧
├── build.bat                # PyInstallerワンクリックビルドスクリプト
└── README.md                # 本説明書
```
